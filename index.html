# CyberLearn Academy A basic cybersecurity learning landing page with per-lesson payment and certificate generation support. ## Setup 1. Install dependencies: npm install 2. Copy `.env.example` to `.env` and fill in your Paystack and email credentials. 3. Start the app: npm start 4. Visit http://localhost:3000 ## Paystack flow - The frontend triggers `/api/initiate-payment`. - The server initializes a Paystack transaction. - After successful payment, the user is redirected to `/payment-callback`. - The server verifies the transaction and emails a certificate PDF. ## Notes - Use Paystack test keys during development. - For production, store files in a proper object storage service instead of the local `certificates` folder. - Add a database if you need persistent records of purchases and certificates.
